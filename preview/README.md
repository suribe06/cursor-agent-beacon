# Display preview

Interactive simulator for the 480×480 desk display (default eye theme).

## Open the simulator

**Live:** [https://suribe06.github.io/cursor-agent-beacon/](https://suribe06.github.io/cursor-agent-beacon/) (deploys from `main` via GitHub Pages)

**Local:**

```bash
xdg-open preview/display-simulator.html
```

Requires `preview/beacon-sprites.js` (generated by `scripts/export_standard_gifs.py`) and `themes/standard/assets/*.gif`.

## What it shows

The same eye GIFs the desk panel plays.

| State key | Agent state | Animation |
|---|---|---|
| `sleeping` | `idle` | Eyes drift shut |
| `waiting` | `waiting` | Happy eyes, glance, blink |
| `thinking` | `thinking` | Eyes look up and around |
| `running_shell` | `running_shell` | Narrow eyes scanning |
| `running_mcp` | `running_mcp` | Steady eyes, green spark |
| `success` | `success` | Smile that pulses |
| `error` | `error` | Shock, then a sweat drop |
| `stop` | `stop` | Laughing eyes |

## Regenerate assets

```bash
pip install Pillow
python3 scripts/export_standard_gifs.py
```

Updates GIFs, `manifest.json`, and `preview/beacon-sprites.js`.

## Controls

- Click any state on the left panel
- **Auto cycle** — rotates through all states
- **Round display** — round bezel (VIEWE Φ80 mm style)
- The bezel plays the bundled GIF for the selected state
